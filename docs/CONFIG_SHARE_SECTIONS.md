# 配置分享：按页签选择（2026-11-12）

来源：共享文档《网页-小程序端》寻道大千区的“所有项目适配”要求。

- 分享窗口默认勾选所有本项目配置页签，包含当前未保存的修改。
- 取消的页签不进入分享码；导入时沿用现有部分配置合并，仅应用码内字段。
- 空选禁止生成；生成后改选会清除当前展示的旧码；读取失败保留勾选，重新打开恢复全选。
- 分享格式、项目 ID、schema 版本、24 小时有效期、认证和密码排除规则不变。
- 应用仅修改页面草稿，仍需手动保存，不自动启动。

## 页签与字段范围

更长的路径优先归属其所在页签，不按存储根节点盲目分组。数组保持完整。隐藏的兼容字段仍随原功能页签保留。

| 页签 | 路径前缀 |
| --- | --- |
| 基础 | `basic` |
| 种植 | `plant` |
| 订单 | `order`, `basic.hasSeparation` |
| 公会 | `union` |
| 活动 | `activity` |
