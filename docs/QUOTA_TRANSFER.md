# 配额转移页面

- 顶部“转移配额”由Dashboard挂载QuotaTransfer。默认关闭，页面提示等待管理员开启。
- 网站账号+整数点数 → 服务端预览 → 六项确认弹窗（转移、到账、手续费、实付、当前余额、剩余） → 服务端提交。规则和示例随服务器费率变化；默认10%向上取整，30点手续费3点、实付33点。
- 成功后刷新导航余额及历史。结果未确认时，按登录用户在sessionStorage保留请求标识及确认内容，切页/刷新后恢复同一请求；超时/503不能换新UUID重发。关闭/费率变化/余额不足明确拒绝后重新预览。
- 管理面板“玩家交易配额”仅isAdminRole显示；QuotaTransferAdmin管理开关、百分比费率、七项全站统计及完整账号搜索。后端另查数据库当前管理员角色。
- PointTransactionHistory是个人中心/转移页/管理查询共用的20条分页组件；显示转出含手续费、转入到账，保留充值/消费等原历史与支付方式。切换用户查询隔离旧请求，读取失败明确提示。
- 统计按北京时间，交易额不含手续费、一笔计一次；交易用户数为历史转入转出双方去重。默认关闭由管理员开启，费率支持0–100%，最多两位小数。

配套接口及迁移见对应Web API仓库docs/QUOTA_TRANSFER.md。先更新后端并完成启动迁移，再部署前端；管理员开启后生效，不涉及游戏脚本。织梦本轮只有后端接口。

scripts/test-quota-transfer-browser.mjs使用专用无头Edge、实际Vue/Ant Design组件及合成HTTP数据，覆盖关停、30/30/3/33/100/67确认金额、提交应答丢失/切页恢复、余额不足、历史分页、管理员费率/开关/查询/统计和390px窄屏。生产构建通过，无真实用户配额操作。

花园显式vue-tsc -p tsconfig.app.json仍有既有类型错误，新增组件未报错；普通生产构建不等同全仓显式类型检查。当前未部署。

管理员接口显式携带管理面板登录令牌；共享Axios保留调用方Authorization，避免被普通用户登录覆盖。浏览器专项另执行真实Axios拦截器验证显式令牌、默认用户、管理员回退和无登录，并验证旧consume负数金额不显示双负号。
