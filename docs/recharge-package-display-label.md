# 充值套餐不限购展示文字

依据2026-09-15《网页-小程序端》果园需求。

## 使用方法

后台「充值套餐 → 添加/编辑套餐」新增「不限购展示文字」，位于「购买次数限制」下方。购买次数填0或留空，展示文字填「限时活动」，充值弹窗对应位置便展示该文字；购买次数仍为不限购。文字留空恢复「无限制」。

文字仅用于展示，不能改变价格、点数、赠送数量、`max_purchase_count`、`user_purchased_count` 或 `can_purchase`。有次数限制的套餐继续展示真实限购次数和已购次数，不允许自定义文字掩盖限制。普通套餐及福利卡套餐采用同一显示规则。

## 新字段和接口对接

| 字段 | 类型 | 默认 | 规则 |
| --- | --- | --- | --- |
| `purchase_limit_label` | string，可兼容null/缺失 | 空字符串 | 去除两侧空白，最长20个字符；仅不限购时替换默认展示文字 |

- 新建/修改：`POST /api/admin/recharge-packages`、`PUT /api/admin/recharge-packages/:id` 的JSON中提交此字段。
- 后台列表：`GET /api/admin/recharge-packages` 的`packages[]`返回此字段，用于列表显示、编辑回填。
- 用户列表：`GET /api/payment/recharge-packages` 的`packages[]`返回此字段，用于首次加载及刷新。
- 旧数据缺少字段或为空仍显示「无限制」。前端沿用既有规则，把编辑值0的`max_purchase_count`保存成null，不用文字字段代替购买次数。

例如：`{"max_purchase_count":null,"purchase_limit_label":"限时活动"}`，表示不限购，文字为「限时活动」，**不表示自动设置活动日期或到期下架**。

本仓库只有前端，本机未找到果园Web API的对应服务源码。服务端必须补齐字段存储、输入校验及上述两个列表的返回；尚未验证线上存储和跨用户显示。不要用浏览器本地缓存代替服务端持久化。本次真实组件测试用模拟后台，不创建支付订单、不执行充值。

## 同份文档的姓名指引

三处「好友名字」已统一为「例如：曼东」：偷取花灵指定好友、偷花排除好友、好友摊位按好友筛选。帮助文字中的名字示例也同步，字段路径、姓名数组和保存规则不变。

## 新版文档：福利卡统一使用「配额」

2026-09-15新版文档新增要求：福利卡相关的「点」改为「配额」。已覆盖赠配额套餐标题、赠福利卡金额、支付完成后的福利卡展示及手续费提示、个人中心福利卡列表、两处兑换确认弹窗，以及后台套餐福利卡设置和卡密管理。

仅调整界面文字。`points`、`gift_card_points`、`points_to_add`、`transfer_fee` 等接口字段、数值、费用计算、兑换限制和购买规则均不变；普通充值及余额区的其他点数文字不在本次福利卡范围内。服务端返回的自定义卡名、手续费原因和消息原文不做全局替换。
